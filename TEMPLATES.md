# First-design banner studies

These four folders use the selected mist-blue design and preserve its content and general visual language. Each explores a different placement for a future photographic or artistic banner.

- `version-1/` — Masthead strip: a wide 6:1 banner directly below the navigation.
- `version-2/` — Full-background hero: the selected artwork fills the opening screen behind the event title.
- `version-3/` — Editorial band: a panoramic 16:5 image between the hero and main content.
- `version-4/` — Exhibition panel: a captioned 3:1 artwork inset within the hero narrative.

Each folder is standalone. Open its `index.html` directly or publish the folder through GitHub Pages or Cloudflare Pages. No build process or remote dependency is required.
